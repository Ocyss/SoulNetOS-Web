# SoulNetOS - AI角色扮演的新范式
SoulNet OS / 万象
SoulNet（灵魂网络）强调角色深度与用户互动的情感联结，OS点明操作系统属性；
万象寓意系统兼容千变万化的内容生态（如插件、角色模板、时间玩法）。

## 项目愿景
打造一个直观、易用且功能强大的AI角色扮演平台，通过模拟手机操作系统的方式，为用户提供沉浸式的线上线下融合互动体验。

## 核心特点

### 1. 跨平台Web应用
- 基于浏览器的手机系统模拟器
- 随时随地可访问
- 响应式设计，支持多种设备

### 2. 系统功能
- 时间系统
  - 支持实时同步
  - 可调节时间流速
  - 时间暂停/继续
  - 自定义时间周期
  - 昼夜交替影响
  
- 状态栏
  - 下拉查看详细信息
  - 可交互时间显示
  - 天气与环境信息
  
- 桌面系统
  - 抽屉式应用列表
  - 可定制小部件
  - 灵活的布局系统
  - 线上/线下模式切换

### 3. 预装应用
- 即时通讯
  - 支持单聊/群聊
  - 多角色互动
  - 角色状态同步
  
- 虚拟小镇
  - 可自定义地图系统
  - 场景探索与互动
  - 地点打卡与记录
  - POI兴趣点系统
  
- 线下模式
  - 沉浸式UI切换
  - 环境描述系统
  - 角色状态实时展示
  - 第三人称叙事
  - 互动动作系统
  
- 系统应用集成
  - 电话系统
  - 短信
  - 浏览器
  - 相册(支持AI插画)
  
- 设置中心
  - API配置管理
  - 系统重置
  - 个性化定制
  - 场景预设管理

### 4. 插件生态
- 应用商店
  - 一键安装社区插件
  - 插件评分与推荐
  - 开发者工具支持
  
- 角色系统
  - 灵活的角色卡配置
  - 记忆与情感模拟
  - 成就系统
  - 角色间互动机制
  - 环境感知与响应

## 技术栈
- 前端: Nuxt3 + Vue3 + NuxtUI + TailwindCSS
- 采用Nuxt4文件夹结构规范
